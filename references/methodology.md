# 三位名师方法论卡片 + 0 基础学习地图

> 所有师资信息均来自公开可核实来源，供 Skill 讲解与出题时引用，不虚构。

## 一、名师方法论卡片

### 玄冰（库课）——学生视角的破冰者
- **资历**：湖北理工学院本科、微软 MOS 大师级认证、教龄 6 年（库课官网）。
- **理念**："用心上好每一节课，用心对待每一位学生"；善于从学生角度出发，总结要点和方法，课堂深入浅出、通俗易懂。
- **可借鉴方法**：生活化类比破冰 + 口诀/顺口溜/小故事记忆钩子 + 由基础平滑到拔高。
- **适用场景**：0 基础入门、概念听不懂、需要降低焦虑建立信心。
- **短板提醒**：体系偏录播、互动弱，需配合主动练习。

### 邵增珍 / 邵博士（廿书教育）——理解本位的结构者
- **资历**：《计算机公共课考点分析与题解》《计算机基础知识综合辅导与强化》主编（百度百科）。
- **理念**："教书者必先强己，育人者必先律己"；不止于"是什么"，更教"为什么"，用更全面视角看待计算机。
- **可借鉴方法**：追问为什么 → 建立知识因果链 → 考点分析 + 题解强化（廿书"必刷 2500 题"）→ 大题量精解析。
- **适用场景**：懂了但记不牢、遇变式题崩、需要体系化根基。
- **短板提醒**：节奏偏学术，纯 0 基础需先破冰。

### 公方胜（海纳教育）——命题视角的提分者
- **资历**：曲阜师范大学计算机科学与技术、15 年专升本计算机教学经验；著有《升本高分领航》《计算机文化基础核心考点》；最高分 98 分（海纳官网/师资页）。
- **理念**：长期从事专升本命题趋势与政策研究，准确预测命题趋势；诙谐幽默、讲解清晰透彻、复杂知识通俗化、实用针对性强。
- **可借鉴方法**：命题人视角反推考点与陷阱 → 真题吃透 → 错题复盘 → 费曼输出（海纳"基础抓牢、真题吃透、错题复盘"三步走）。
- **适用场景**：临考冲刺、拿分导向、查漏补缺精准提分。
- **短板提醒**：基础不牢直接冲命题视角易"背答案而非懂原理"。

## 二、融合原则

三者是学习进阶的三层，不可偏废：
- 只有玄冰 → 听懂但不会做
- 只有邵博士 → 懂但记不住应试点
- 只有公方胜 → 会考但不懂原理、遇变式崩盘

**正确顺序**：玄冰破冰（入口）→ 邵博士立根（根基）→ 公方胜提分（出口），全程贯穿海纳式错题复盘 + 费曼输出。

## 三、0 基础学习地图（按山东考纲顺序）

| 阶段 | 章节 | 主导方法 | 关键动作 |

| 阶段0 破冰 | 第1章 信息与计算机基础（进制/编码/硬件/单位） | 玄冰法 | 生活类比 + 口诀记单位换算 |

| 阶段4 冲刺 | 第7-11章 数据库/网络/多媒体/安全/新技术 | 公方胜法 | 命题视角抓高频，真题吃透，押题清单 |

## 四、费曼复述模板（复盘用）

让学生用自己的话回答三问，任一卡壳回讲：
1. 这个概念是**什么**？（玄冰层：能否通俗说清）
2. 它**为什么**是这样 / 和其他概念什么关系？（邵博士层：因果链）
3. 考试会**怎么考**、我容易**错在哪**？（公方胜层：命题陷阱）
