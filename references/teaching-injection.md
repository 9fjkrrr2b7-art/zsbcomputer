# 教案 / PPT 嵌入名师授课思路与方法（范式与示例）

> 用途：当用本 skill 产出「教案」或「PPT」时，可附加「名师授课思路卡」，让授课设计自带三位名师的教学法基因。
> 三位名师基因：玄冰（库课）破冰引入 · 邵增珍/邵博士（廿书）讲透为什么 · 公方胜（海纳）命题点拨。

## 一、名师授课思路卡（每节课 / 每页可附一张或多张）

### 玄冰式 · 破冰引入（教案「导入」环节 / PPT 首屏）
- **核心**：用学生熟悉的生活类比 + 一句记忆口诀，把抽象概念降到 0 基础可懂。
- **模板**：「用一个生活场景类比【概念】，并给一句记忆口诀。」
- **示例（CPU 组成）**：把 CPU 比作「工厂车间」——运算器是加工机床，控制器是调度主任；口诀「运控一家，CPU 当家」。
- **示例（进制）**：把二进制比作「电灯开关只有开/关两态」，所以计算机只用 0/1。

### 邵博士式 · 讲透为什么（教案「新授」核心 / PPT 原理页）
- **核心**：不只说「是什么」，要讲清「为什么这样」和前后因果链，建立结构化理解。
- **模板**：「指出【概念】为什么如此，它与前后知识的因果关系，画出逻辑链。」
- **示例（为什么用二进制）**：电子器件只有通/断两态，二进制最稳定、运算规则最简、抗干扰最强，所以计算机底层用 0/1 而非十进制。
- **示例（为什么 1GB=1024MB）**：内存按 2 的幂编址，2^10=1024，故存储单位以 1024 为进率，而非 1000。

### 公方胜式 · 命题点拨（教案「小结/作业」 / PPT 收尾页）
- **核心**：点出该考点在专升本考试中的常见考法、易错点、真题出处，把知识翻译成分数。
- **模板**：「指出本节【考点】的命题陷阱、高频考法、易错点与真题来源。」
- **示例（文件命名）**：易错——误用 `?` `*` 作文件名、误以为区分大小写；真题常考命名规则判断题。
- **示例（ASCII）**：陷阱——把「标准 ASCII 7 位 128 个」与「扩展 ASCII 8 位 256 个」混为一谈。

## 二、教案嵌入范式（导入 / 新授 / 小结 三段）

| 教案环节 | 嵌入名师思路 | 产出物 |
|---|---|---|
| 导入 | 玄冰式破冰类比 + 口诀 | 1 段生活化引入 + 1 句口诀 |
| 新授 | 邵博士式讲透为什么 + 结构化 | 因果链 / 流程图 + 关键词 |
| 小结 / 作业 | 公方胜式命题点拨 + 真题 | 易错点清单 + 1 道对应真题 |

## 三、PPT 嵌入范式（每章 / 每节）

- **封面后**：玄冰式引入页（生活类比 + 口诀）
- **原理页备注**：邵博士式「为什么」讲稿
- **收尾页**：公方胜式命题点拨（易错 + 真题）
- **每页可选**：在备注栏附对应「名师授课思路卡」

## 四、调用示例

- 「写第 3 章操作系统的教案，导入用玄冰、原理用邵博士、收尾用公方胜」→ 按上表三段嵌入。
- 「做进制转换的 PPT，每一页备注里写名师怎么讲」→ 每页备注附对应名师思路卡。
- 「帮我写 Word 排版的教案，要带上三位老师各自的讲法」→ 每个重难点并列三位思路，供教师择用。
