## 样例 1（单选·基础·第1章）

【1】单选｜第1章 数据与编码｜基础
题干：标准 ASCII 码用 7 位二进制表示，在计算机中存储时最高位固定为（ ）。
A. 0  B. 1  C. 不确定  D. 空格

考点：第1章 ASCII 码存储（最高位补 0）
易错点：误以为最高位参与编码或随意。
答案：A
解析：
  为什么：标准 ASCII 仅用 7 位表示 128 个字符，为凑足 1 字节，最高位补 0。
  典型错因：选 B 的同学把"扩展 ASCII（8 位 256 个）"与"标准 ASCII"混淆。
  命题陷阱：题干强调"标准"，借"扩展 ASCII"设干扰。

## 样例 2（多选·中等·第3章）

【2】多选｜第3章 操作系统 Win10｜中等｜正确项数 2–4
题干：下列关于 Windows 10 文件命名的说法，正确的有（ ）。
A. 文件名不能包含字符 `?` 和 `*`
B. 同一文件夹下 `TEST.docx` 与 `test.docx` 视为同名冲突
C. 文件名最长 255 个字符（不含路径）
D. 文件名区分大小写

考点：第3章 文件命名规则
易错点：误以为区分大小写、误以为可用 `?`/`*`。
答案：ABC
解析：
  为什么：Windows 文件名禁用 `\ / : * ? " < > |`；不区分大小写（TEST 与 test 视为相同）；最长 255 字符不含路径。D 错在"区分大小写"。
  典型错因：选 D 的同学受 Linux 习惯影响；漏选 B 的同学不清楚不区分大小写导致同名冲突。
  命题陷阱：D 借 Linux 文件系统特征反向设误。

## 样例 3（单选·拔高·第5章）

【3】单选｜第5章 Excel 2016｜拔高
题干：在 Excel 2016 中，若单元格 B1 公式为 `=A$1`，将其复制到 C2，C2 中的公式变为（ ）。
A. =B$1  B. =A$2  C. =B$2  D. =A$1

考点：第5章 相对/绝对引用（列相对、行绝对）
易错点：混淆 `$` 锁定方向。
答案：A
解析：
  为什么：`$1` 锁定行 1，列 A 相对。复制到右侧一列、下侧一行后，列变 B、行仍锁 1 → `=B$1`。
  典型错因：选 C 的同学把 `$1` 误当成锁定列；选 D 的同学以为完全不随位置变化。
  命题陷阱：借"混合引用"中常见误解设项。
