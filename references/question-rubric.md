# 命题人 / 阅卷人视角：出题严格评判标准

> 立场：命题人负责"考得准、区分度好"；阅卷人负责"给分得公平、错因可溯"。
> 任何由 Skill 生成的题目，必须先过下方「自检打分卡」再交付。

## 一、考点覆盖度（命题人）
- 对照 `exam-outline.md` 的 11 章按权重出题：基知/操作系统/Office 三件套为绝对重点（合计约 60%+）。
- 每套题须覆盖"概念 / 原理 / 操作 / 易错"四维度，避免只考记忆。
- 多选题严格 2–4 个正确项；严禁全选或退化成单选。

## 二、干扰项质量（阅卷人看错误分布）
干扰项**必须源自真实学生错误**，单一干扰项只设一个陷阱点：
- 概念混淆：位(bit) vs 字节(Byte)、ROM vs RAM、TCP vs UDP、运算器 vs 控制器
- 生活误导：1MB = 1000KB（应为 1024）、八位有符号范围含 +128、标准 ASCII 256 字符（实为 128）
- 版本混淆：Win7 / Office 2010（考纲已弃用，属错误项陷阱或应规避的过时表述）
- 相近概念：ASCII 最高位补 0、汉字机内码 2 字节、字长 vs 字

## 三、高频易错点清单（失分重灾区）
| 模块 | 易错点 |
|---|---|
| 进制与编码 | 十↔二↔十六转换方向、ASCII 最高位为 0、原/反/补码、汉字 2 字节 |
| 存储单位 | 1GB=1024MB 链、字 vs 字长、bit/Byte 区分 |
| 操作系统 | 文件命名禁用 `\ / : * ? " < > |`、不区分大小写、Ctrl+Shift+Esc 开任务管理器 |
| 网络 | IP 的 A/B/C 类划分、DNS/HTTP 作用、拓扑类型 |
| Office 2016 | 功能区/快速访问工具栏、Excel 相对/绝对引用、PPT 母版与交互 |
| 信息安全 | 病毒本质（破坏程序/数据）、防火墙位置、加密概念 |

## 四、评分要点与阅卷宽容度
- **概念题**：命中关键词即给分（如"运算器+控制器组成 CPU"），不要求原话。
- **多选题（山东规则）**：漏选得部分分、错选 0 分；生成题须明确标注"正确项数"。
- **操作题**：步骤顺序正确即可，关键步骤缺失扣分，结果正确可酌情给分。

## 五、出题蓝图（难度配比）
- 配比：**基础 60% + 中等 30% + 拔高 10%**。
- 每题必附字段：`考点 / 难度 / 易错点 / 标准答案 / 解析（含"为什么"+ 典型错因）`。

## 六、自检打分卡（生成题逐条校验，全部打勾方可交付）
- [ ] 考点明确且在考纲 11 章内
- [ ] 干扰项有真实错误来源（非臆造）
- [ ] 答案唯一 / 多选题正确项数 2–4 且已标注
- [ ] 解析含"为什么"与典型错因
- [ ] 无 Win7 / Office 2010 等过时版式表述
- [ ] 难度与蓝图配比一致
- [ ] 覆盖维度含"易错点"提示

> 任一未打勾 → 修改该题或丢弃，绝不带病交付。
